# homework_10_1 Работа с внешним API и тестированием

## 📌 Описание проекта

Проект реализует:
- загрузку операций из JSON-файла;
- конвертацию суммы транзакции в рубли с использованием внешнего API;
- тестирование функций с помощью pytest;
- проверку качества кода с flake8 и mypy, isort, black

## Запуск тестов

pytest -v

## Логирование

В проекте настроено логирование для модулей:

- **masks** — маскировка номеров карт и счетов  
- **utils** — загрузка операций из JSON-файлов  

Особенности логирования:

- Отдельные логеры для каждого модуля (`masks.log`, `utils.log`)  
- Логи сохраняются в папку `logs/` в корне проекта  
- Формат записи: `время | модуль | уровень | сообщение`  
- Уровень логирования:
  - `DEBUG` — успешные операции функций  
  - `ERROR` — ошибки и исключения  
- Файлы логов перезаписываются при каждом запуске приложения

from utils import load_operations
