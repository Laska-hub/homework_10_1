# homework_10_1 Работа с внешним API и тестированием

## 📌 Описание проекта

Проект реализует:
- загрузку операций из JSON-файла;
- конвертацию суммы транзакции в рубли с использованием внешнего API;
- тестирование функций с помощью pytest;
- проверку качества кода с flake8 и mypy, isort, black

## Запуск тестов

pytest -v
